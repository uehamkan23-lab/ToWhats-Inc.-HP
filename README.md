# 常奥株式会社 ToWhats Inc. — コーポレートサイト

常陸・陸奥から笑顔を届ける。

HTML / CSS / JavaScript のみで作られた、依存パッケージなしの静的サイトです。
ビルド不要。`index.html` をブラウザで開けばそのまま動きます。

---


## 実装している機能

- **日本語 / 英語の切り替え** — ヘッダー右上の `JA / EN`。選択は `localStorage` に保存される
- **ライト / ダークテーマ** — 初期状態は OS の設定に追従。手動切替も保存される
- **スクロール演出** — `IntersectionObserver` による各要素のフェードイン、見出しの一文字ずつの表示、スクロール進捗バー、現在地に応じたナビの点灯
- **モバイル対応** — 860px 以下でハンバーガーメニュー。横スクロールは発生しない
- **アクセシビリティ** — 本文へのスキップリンク、キーボード操作、`prefers-reduced-motion: reduce` で全アニメーション停止

外部ライブラリは使用していません。外部への通信は Google Fonts（Noto Sans JP / Noto Serif JP / JetBrains Mono）の読み込みのみで、読み込めない環境でも OS 標準の明朝・ゴシックにフォールバックします。

## ローカルでの確認

`index.html` をダブルクリックして開くだけでも動きます。
ローカルサーバーで確認する場合は、このフォルダで次を実行してください。

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## 公開（デプロイ）

公開先は未定です。GitHub Pages を使う場合の手順は次の通りです。

1. GitHub のリポジトリ → **Settings** → **Pages**
2. Source を **Deploy from a branch** にする
3. Branch に公開したいブランチ、フォルダに `/ (root)` を選んで **Save**
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

Vercel や Netlify を使う場合も、ビルド設定は不要です（フレームワークなし、出力ディレクトリはルート）。
