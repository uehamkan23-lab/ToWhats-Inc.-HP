# 常奥株式会社 ToWhats Inc. — コーポレートサイト

常陸・陸奥から笑顔を届ける。

HTML / CSS / JavaScript のみで作られた、依存パッケージなしの静的サイトです。
ビルド不要。`index.html` をブラウザで開けばそのまま動きます。

---

## ファイル構成

```
.
├── index.html      マークアップ（日本語をベースに、英語は data-en 属性で保持）
├── style.css       デザイントークン、レイアウト、アニメーション
├── script.js       言語切替・スクロール演出
├── assets/
│   ├── README.md              画像の差し替えガイド（要確認）
│   ├── logo-placeholder.svg   ロゴ（仮）
│   ├── favicon.svg            ファビコン（仮）
│   ├── placeholder-member.svg メンバー写真（仮・円形に切り抜いて表示）
│   └── placeholder-work.svg   プロダクトの画面（仮）
└── README.md       このファイル
```

## デザイン方針

**情報の引き算。** 黒と白のセクションを交互に置き、大きな文字と余白だけで見せます。
1つの画面で伝えることは1つだけ。説明文は見出し＋1行までに絞っています。

## セクション構成

| セクション | 背景 | 内容 |
|---|---|---|
| Hero | 黒 | キャッチコピー |
| About | 白 | 会社の説明（スクロールに合わせて文字が灰色から黒に変わる） |
| Philosophy | 薄灰 | 三つの理念（画面に固定され、スクロールで1つずつ切り替わる） |
| Works | 黒 | NajoshiteAI（スクロールで画像が拡大する） |
| Team | 白 | 役員4名 |
| Company | 薄灰 | 社名・所在地・設立・代表 |

## 実装している機能

- **日本語 / 英語の切り替え** — ナビ右上のボタン。選択は `localStorage` に保存される
- **スクロール連動の演出** — `requestAnimationFrame` で1フレームに1回だけ計算。ライブラリなし
- **日本語の改行位置** — `Intl.Segmenter` で文節に区切り、「会／社」のような単語の途中で改行しないようにしている。CSS の `word-break: auto-phrase` も併用
- **モバイル対応** — 833px 以下でメニューが全画面表示に切り替わる
- **アクセシビリティ** — `prefers-reduced-motion: reduce` の環境では、固定表示・拡大・文字の色変化をすべて止め、通常の縦並びで表示する。JavaScript が無効でも全文が読める

外部ライブラリは使用していません。外部への通信は Google Fonts（Inter / Noto Sans JP）の読み込みのみです。Apple 製品では San Francisco とヒラギノ角ゴが優先して使われます。

## ローカルでの確認

`index.html` をダブルクリックして開くだけでも動きます。
ローカルサーバーで確認する場合は、このフォルダで次を実行してください。

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## 公開（デプロイ）

公開先は未定です。GitHub Pages を使う場合の手順は次の通りです。

1. GitHub のリポジトリ → **Settings** → **Pages**
2. Source を **Deploy from a branch** にする
3. Branch に公開したいブランチ、フォルダに `/ (root)` を選んで **Save**
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

Vercel や Netlify を使う場合も、ビルド設定は不要です（フレームワークなし、出力ディレクトリはルート）。
