# 常奥株式会社 ToWhats Inc. — コーポレートサイト

常陸・陸奥から笑顔を届ける。

HTML / CSS / JavaScript のみで作った静的サイトです。ビルド不要、依存パッケージなし。
`index.html` をブラウザで開けばそのまま動きます。

---

## デザインコンセプト：ポップな日の出

- **土地から** — 藍色の夜明け空と、波の向こうから昇る朝日。キャッチコピー「常陸・陸奥から笑顔を届ける」をそのまま絵にしています
- **遊び心から** — レトロポスターのような色の帯、極太ゴシック、傾いたカード、ステッカー、流れるテロップ、触ると跳ねる動き
- **共通の決まり** — 太い藍色の枠線（3px）と、ずらした影。これで全要素をポップに揃えています

| 色 | 値 | 使いどころ |
|---|---|---|
| 藍 | `#1a2456` | 文字・枠線・影・夜空 |
| 朝日の黄 | `#ffc83d` | 太陽・テロップ・会社概要の背景 |
| 橙 | `#ff8f3f` | 朝焼け・メンバーの背景 |
| コーラル | `#f0645f` | 見出しの影・ステッカー・カード |
| 生成り | `#fff7e8` | ページの背景 |

フォントは **Dela Gothic One**（見出し）と **Zen Kaku Gothic New**（本文）。どちらも Google Fonts、SIL Open Font License です。

| セクション | 内容 |

| Hero | 日の出の風景とキャッチコピー、「設立準備中！」ステッカー |
| テロップ | 傾いた黄色い帯に、キャッチコピーなどが流れ続ける |

| メンバー | 役員4名 |

## 動き

- 読み込み時、太陽が波の下から昇り、見出しが弾むように現れる
- スクロールすると太陽がさらに昇り、見出しは逆方向にゆっくり動く
- 波は3層それぞれ別の速さで流れ続ける
- 各セクションは、画面に入ると下からバネのように現れる
- カード・写真・ボタンは、マウスを乗せると傾きが戻ったり跳ねたりする

`prefers-reduced-motion: reduce`（動きを減らす設定）の環境では、すべての動きを止めます。JavaScript が無効でも全文が読めます。


## 公開（デプロイ）

公開先は未定です。GitHub Pages の場合：

1. GitHub のリポジトリ → **Settings** → **Pages**
2. Source を **Deploy from a branch** にする
3. 公開したいブランチと `/ (root)` を選んで **Save**

Vercel や Netlify でもビルド設定は不要です（フレームワークなし、出力ディレクトリはルート）。
