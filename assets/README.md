# assets / 画像の差し替えガイド

このフォルダの画像は、すべて**仮のプレースホルダー**です。
本番の画像ができたら、**同じファイル名で上書き**すれば、HTML を触らずに差し替わります。
（形式を変える場合、例えば `.svg` → `.png` は、`index.html` のパスも変更してください）

---

## 1. ロゴ（受け取り済み）

いただいた2つのロゴを、次のように加工して使っています。元の画像は `source/` にそのまま保存してあります。

| ファイル | 使う場所 | 加工内容 |
|---|---|---|
| `logo-header.png` | ヘッダー（高さ 40px で表示） | 余白を切り取り、幅 800px に縮小 |
| `logo.png` | 今は未使用（OGP 画像などに使う予定） | 余白を切り取り、幅 1000px に縮小 |
| `logo-mark.png` / `logo-kanji-jo.png` / `logo-kanji-oku.png` | オープニング画面 | ロゴ全体を「赤いマーク」「常」「奥」の3つに分割。並べると元のロゴと同じ配置になる |

ロゴの赤（`#d70009`）は、サイト全体の差し色としても使っています。

## 2. `favicon.png` — ファビコン

ブラウザのタブに出る小さなアイコンです。ヘッダーのロゴから「To」の赤いマーク部分を切り出して作りました。
16px 程度まで小さくなるので、専用の簡略版（線を太く・形を単純に）を描いてもらえれば、そちらに差し替えます。

## 3. `people/` — メンバーと活動の写真（受け取り済み）

`orera/` フォルダにいただいた写真を、次のように加工しています。

| ファイル | 元の写真 | 使う場所 |
|---|---|---|
| `uehara.webp` / `anzai.webp` / `kobayashi.webp` / `yuki.webp` | `orera/上原` などの各フォルダ | トップ右下の4人、メンバーの丸い写真 |
| `fun-pitch.webp` | `orera/とわつ/IMG_0069.png` | トップ左上（Let's play!） |
| `fun-jump.webp` | `orera/とわつ/無題34…png` | トップ中央（課題・不満を飛び越える） |
| `fun-silhouette.webp` | `orera/とわつ/無題42…png` | トップ右上 |
| `fun-duo.webp` | `orera/とわつ/IMG_0070.png` | トップ左下 |
| `fun-peek.webp` | `orera/とわつ/無題35…png` | 「私たち」の左端から覗く |
| `fun-catch.webp` | `orera/とわつ/無題41…png` | 「私たち」の右下 |

### 加工の内容

- **メンバー4人の写真**：写真に描いてもらった白い線を「切り取り線」として使い、線の外側の背景（海・テトラポッド・壁）を消しました。そのうえで、細い線を取り除き、**太さの揃った白いふち**を付け直しています
- **「とわつ」の写真**：もともと背景が透過だったので、同じ太さの白いふちだけを付けました。`無題41` は、奥の小さな人物が本体とつながっていなかったため、手前の人物だけを使っています
- すべて **WebP** に変換しています（10枚で 4.3MB → 444KB）

### もっと綺麗にするには

メンバー写真は、白い線と体のあいだに**元の背景が少し残っている**ところがあります（とくに安齋さんの右側）。
次のどちらかをいただければ、より綺麗なステッカーになります。

- 背景を切り抜いた（透過）PNG
- 白い線を、体の輪郭により近く描き直したもの

## 6. オープニング画面（サイトを開いたときに出る画面）

サイトを開くと、約3秒間だけ生成り色の画面が出ます。**ロゴの赤いマークが上から落ちてきて → V字の先を支点に2回、噛むように傾き → 一度ためて → 「常」「奥」が1文字ずつ飛び出し → 幕が上がるように消える**、という流れです。
「小さく2回動いて、ためて、大きく動く」というリズムは、参考サイト（shishi-w.com）のロゴが上下に分かれて2回噛むように動く演出を参考にしています。

| 項目 | 内容 |
|---|---|
| 使っている画像 | `logo-mark.png` / `logo-kanji-jo.png` / `logo-kanji-oku.png` |
| 表示サイズ | ロゴ全体で横 380px（スマホでは画面幅の 72%） |
| 背景色 | 生成り `#fff7e8`（黒い「常奥」と赤いマークが映える色） |
| 長さ | 3.3 秒で幕が上がります |

ロゴのデザインが変わったときは、元画像をいただければ同じように3つに分割し直します。

### 動作の仕様

- **1つのタブにつき1回だけ**表示されます。ページを移動したり再読み込みしたりしても、同じタブではもう出ません（確認したいときは、新しいタブで開いてください）
- 画面のどこかをタップ、または Esc / Enter / スペースキーで、すぐに飛ばせます
- 端末で「視差効果を減らす／動きを減らす」設定をしている人には表示しません
- 何かの理由でスクリプトが動かなくても、5秒後には必ず消えるようにしてあります

## アイコンについて

使っているアイコンは、ボタンの「→」と、手書きラベルのくるっとした矢印の2つだけです。どちらも自前で描いた SVG を `index.html` に直接埋め込んでいます（絵文字は不使用、ライセンスの制約なし）。
