# assets / 画像の差し替えガイド

このフォルダの画像は、すべて**仮のプレースホルダー**です。
本番の画像ができたら、**同じファイル名で上書き**すれば、HTML を触らずに差し替わります。
（形式を変える場合、例えば `.svg` → `.png` は、`index.html` のパスも変更してください）

---

## 1. ロゴ（受け取り済み）

いただいたトワツのロゴ（黒い線に赤と青）を、次のように加工して使っています。元の画像は `source/towatsu-logo-original.jpg` にそのまま保存してあります。

| ファイル | 使う場所 | 加工内容 |
|---|---|---|
| `logo-mark.png` | ヘッダー（右に「トワツ」の文字）・フッター（クリーム色の台紙）・ファビコンの元 | 白い背景を透明にし、余白を切り取り（750 × 839 px） |

- 白い背景を透明にしたので、輪の内側は下の色が透けて見えます。クリーム色の上に置くと元の画像と同じ見た目になります
- `source/` の `logo-full-original.png` / `logo-header-original.png` は、前の「常奥」のロゴです（今は使っていません）
- NajoshiteAI のロゴ（黄色）の元画像は `source/najoshiteai-logo-original.jpg` です。作品展示会の NajoshiteAI の表紙に使っています

赤（`#d70009`）は、サイト全体の差し色としても使っています。

## 2. `favicon.png` / `favicon-32.png` / `apple-touch-icon.png` — ファビコン

ブラウザのタブや、iPhone のホーム画面に出るアイコンです。トワツのマーク（`logo-mark.png`）を、クリーム色の四角に乗せて作りました。暗い色のタブでも黒い線が見えるよう、背景を付けています。

| ファイル | 大きさ | 使う場所 |
|---|---|---|
| `favicon-32.png` | 32 × 32 | ブラウザのタブ |
| `favicon.png` | 256 × 256 | 高解像度の画面のタブ・ブックマーク |
| `apple-touch-icon.png` | 180 × 180 | iPhone のホーム画面（角は iPhone が自動で丸める） |

## 3. `people/` — メンバーと活動の写真（受け取り済み）

`orera/` フォルダにいただいた写真を、次のように加工しています。

| ファイル | 元の写真 | 使う場所 |
|---|---|---|
| `uehara.webp` / `anzai.webp` / `kobayashi.webp` / `yuki.webp` | `orera/上原` などの各フォルダ | トップ右下の4人、メンバーの丸い写真 |
| `fun-pitch.webp` | `orera/とわつ/IMG_0069.png` | トップ左上（Let's play!） |
| `fun-jump.webp` | `orera/とわつ/無題34…png` | トップ中央（課題・不満を飛び越える） |
| `fun-silhouette.webp` | `orera/とわつ/無題42…png` | トップ右上 |
| `fun-duo.webp` | `orera/とわつ/IMG_0070.png` | トップ左下 |
| `fun-peek.webp` | `orera/とわつ/無題35…png` | 「私たち」の左端から覗く |
| `fun-catch.webp` | `orera/とわつ/無題41…png` | 「私たち」の右下 |

### 加工の内容

- **メンバー4人の写真**：写真に描いてもらった白い線を「切り取り線」として使い、線の外側の背景（海・テトラポッド・壁）を消しました。そのうえで、細い線を取り除き、**太さの揃った白いふち**を付け直しています
- **「とわつ」の写真**：もともと背景が透過だったので、同じ太さの白いふちだけを付けました。`無題41` は、奥の小さな人物が本体とつながっていなかったため、手前の人物だけを使っています
- すべて **WebP** に変換しています（10枚で 4.3MB → 444KB）

### もっと綺麗にするには

メンバー写真は、白い線と体のあいだに**元の背景が少し残っている**ところがあります（とくに安齋さんの右側）。
次のどちらかをいただければ、より綺麗なステッカーになります。

- 背景を切り抜いた（透過）PNG
- 白い線を、体の輪郭により近く描き直したもの

## 4. 作品の画像（トワツ作品展示会）

作品の画像は、書く画面で「作品展示会の作品」を選び、本文に「画像を追加」すると保存されます。「表紙の画像」に選んだものがカードに出ます（横長 16:9 で切り抜き）。
NajoshiteAI の表紙は、いただいた NajoshiteAI のロゴ（黄色）を横長に広げたものです（`works/najoshiteai/logo.webp`）。前の表紙だったアプリの画面（`cover.webp`）は、作品ページの本文に載せています。

WasuFinder とミルクラフトには、まだ画像がありません（名前の1文字目を大きく表示しています）。写真や画面があれば、書く画面から追加してください。

### トップのイラスト2枚（描いてほしいもの）

トップの「イラスト予定」の枠は外しました。描いてもらえたら、ステッカーとしてトップに追加します。参考サイトの「おそば」「お城」「恐竜」のように、**地元らしさが一目でわかるもの**を、ステッカー風に描いてもらえると完成します。

| 場所 | 描いてほしいもの | サイズ |
|---|---|---|
| 右上 | **閖上（名取）の海から昇る朝日**。トワツの目標「答えは探求心の中にある。その探求心の着火剤を創る。」とつながる絵 | 正方形 800 × 800 px |
| 中央下 | **仙台高専の校舎**（名取キャンパス）、または高専らしいもの（ロボット、工具など） | 正方形 800 × 800 px |

- 背景は**透過**にしてください。こちらで白いふちと影を付けます
- 色は自由です。背景が赤（`#e0433a`）なので、**赤以外の色**が中心だと目立ちます
- いただいたら、写真のステッカーと同じように白いふちを付けて貼ります

## アイコンについて

使っているアイコンは、ボタンの「→」と、手書きラベルのくるっとした矢印の2つだけです。どちらも自前で描いた SVG を `index.html` に直接埋め込んでいます（絵文字は不使用、ライセンスの制約なし）。
