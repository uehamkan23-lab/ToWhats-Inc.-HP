# assets / 画像の差し替えガイド

このフォルダの画像は、すべて**仮のプレースホルダー**です。
本番の画像ができたら、**同じファイル名で上書き**すれば、HTML を触らずに差し替わります。
（形式を変える場合、例えば `.svg` → `.png` は、`index.html` のパスも変更してください）

---

## 1. `logo-placeholder.svg` — ロゴ

| 項目 | 内容 |
|---|---|
| 使う場所 | 画面上部の、生成り色のナビ（左端） |
| 表示サイズ | 36 × 36 px |
| 形式 | SVG 推奨／PNG なら 200 × 200 px 以上・背景透過 |
| 今の仮画像 | 黄色い丸に藍色の「常」 |

背景は生成り色（`#fff7e8`）です。**カラーのロゴがそのまま使えます**。
横長のロゴ（マーク＋社名）の場合は、ナビの社名テキストと重複するので、その旨を教えてください。表示を調整します。

## 3. `placeholder-member.svg` — メンバー（4人）

| 項目 | 内容 |
|---|---|
| 使う場所 | メンバーのセクション |
| 表示 | **円形に切り抜き**、1人ずつ違う色の丸の上に置く（黄・コーラル・橙・水色） |
| 推奨サイズ | 800 × 800 px 以上の正方形 |

### おすすめ：似顔絵イラスト（描いてほしいもの）

このデザインは写真よりも**イラストの方が世界観に合います**。

- 4人それぞれの**胸から上の似顔絵**
- 線は**太めの藍色**（`#1a2456`）、塗りはシンプルに
- **背景は透過**（後ろの色の丸がそのまま背景になります）
- 4人とも**同じ画風・同じ構図**（顔が中央、少し笑顔）
- 余裕があれば、それぞれの**役割がわかる小物**（CEO＝旗、CFO＝電卓、CDO＝ペン、CSO＝地図 など）

### 写真を使う場合

- **背景を切り抜いた（透過）PNG** にすると、色の丸と馴染みます
- 切り抜かない場合も使えます（そのまま円形に表示されます）

ファイル名は次の形でください。受け取ったら `index.html` の4か所をこちらで書き換えます。

```
assets/member-uehara.png     上原 貫太 さん（CEO）
assets/member-anzai.png      安齋 隼 さん（CFO）
assets/member-kobayashi.png  小林 壮志 さん（CDO）
assets/member-yuki.png       結城 敬蔵 さん（CSO）
```

## 6. オープニング画面（サイトを開いたときに出る画面）

サイトを開くと、約3秒間だけ藍色の画面が出ます。**太陽が地平線から2回ひょこっと顔を出し → 一度ためてから弾むように昇り → ロゴが飛び出し → 社名が出て → 幕が上がるように消える**、という流れです。
「小さく2回動いて、ためて、大きく動く」というリズムは、参考サイト（shishi-w.com）のロゴが2回噛むように動いてから開く演出を、日の出に置き換えたものです。
今の絵は仮のもので、次の「スロット」部分を差し替えられるようにしてあります。

| 項目 | 内容 |
|---|---|
| 差し替える場所 | `index.html` の `<div class="opening__art">` の中身 |
| 表示サイズ | 横 200 × 縦 130 px（高解像度用に **400 × 260 px** で作ってください） |
| 背景色 | 藍 `#1a2456`（絵の背景は**透過**にすると、藍色の上に自然に乗ります） |
| 長さ | **3秒前後**（今は 3.3 秒で幕が上がります。長さに合わせてこちらで調整します） |

### 作り方の選択肢

1. **ロゴだけ差し替える**：一番簡単です。ロゴの画像をいただければ、今の「太陽が昇る」動きはそのままで、ロゴだけ本物になります
2. **動く絵を作る**：次のどれかの形式でください
   - **アニメーション SVG**（おすすめ。軽くて、どの画面サイズでもくっきり表示されます）
   - **背景透過の動画**（WebM）。MP4 の場合は背景を藍 `#1a2456` で塗ってください
   - **Lottie（JSON）**。After Effects で作る場合はこれ。読み込み用のライブラリを1つ追加します
   - GIF は画質が荒くなるので、おすすめしません
3. **絵コンテだけ描く**：「最初にこれが出て、次にこう動く」という流れを紙に描いて写真を送ってもらえれば、それをコードで動かします

### 動作の仕様

- **1つのタブにつき1回だけ**表示されます。ページを移動したり再読み込みしたりしても、同じタブではもう出ません（確認したいときは、新しいタブで開いてください）
- 画面のどこかをタップ、または Esc / Enter / スペースキーで、すぐに飛ばせます
- 端末で「視差効果を減らす／動きを減らす」設定をしている人には表示しません
- 何かの理由でスクリプトが動かなくても、5秒後には必ず消えるようにしてあります

## アイコンについて

使っているアイコンは、ボタンの「→」と、テロップの「✦」型の星の2つだけです。どちらも自前で描いた SVG を `index.html` に直接埋め込んでいます（絵文字は不使用、ライセンスの制約なし）。
