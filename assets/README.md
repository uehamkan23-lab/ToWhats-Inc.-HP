# assets / 画像の差し替えガイド

このフォルダの画像は、すべて**仮のプレースホルダー**です。
本番の画像が用意できたら、**同じファイル名で上書き**すれば、HTML を編集しなくても差し替わります。
（ファイル名を変える場合は `index.html` 内のパスも一緒に変更してください）

---

## 1. `logo-placeholder.svg` — ロゴ

| 項目 | 内容 |
|---|---|
| 用途 | ヘッダー左上のシンボルマーク |
| 表示サイズ | 34 × 34 px（正方形） |
| 推奨形式 | SVG（推奨） / PNG なら 200 × 200 px 以上、背景透過 |
| 現在の中身 | 「常」の一文字を藍色の枠で囲んだ仮マーク |

**お願いしたいこと**
既存のロゴをいただければ、そのまま差し替えます。
ライト／ダーク両方のテーマで表示されるので、**白背景でも黒背景でも視認できる色**だと安全です。
もし片方でしか映えない場合は、2ファイル（`logo-light.svg` / `logo-dark.svg`）いただければ、テーマに応じて切り替える処理を追加します。

## 2. `favicon.svg` — ファビコン

| 項目 | 内容 |
|---|---|
| 用途 | ブラウザのタブ、ブックマークのアイコン |
| 表示サイズ | 16 × 16 px 相当まで縮小される |
| 推奨形式 | SVG |

**お願いしたいこと**
ロゴをそのまま縮小すると潰れることが多いので、**マークだけを切り出した、線の太い簡略版**があると理想的です。
なければ、いただいたロゴからこちらで簡略版を作ります。

## 3. `placeholder-member.svg` — メンバーの顔写真（4枚）

| 項目 | 内容 |
|---|---|
| 用途 | Members セクション |
| 表示サイズ | 正方形（1:1）でトリミング表示 |
| 推奨サイズ | 800 × 800 px 以上 |
| 推奨形式 | JPG または WebP |

**用意していただきたいファイル**

```
assets/member-uehara.jpg    上原 貫太 さん
assets/member-anzai.jpg     安齋 隼 さん
assets/member-kobayashi.jpg 小林 壮志 さん
assets/member-yuki.jpg      結城 敬蔵 さん
```

**撮り方の希望**
- 4人とも**同じ場所・同じ明るさ**で撮ると、並べたときに揃って見えます
- 顔が中央、胸から上くらいの構図
- 背景は無地の壁、または作業場所など。ごちゃごちゃしていなければOK
- 顔写真を出したくない場合は、**後ろ姿・手元・アイコンイラスト**でも成立するデザインです

※ 写真をいただいた時点で、`index.html` の `src` をこちらで4つ書き換えます。

## 4. `placeholder-work.svg` — NajoshiteAI のサムネイル

| 項目 | 内容 |
|---|---|
| 用途 | Works セクションのカード |
| 表示サイズ | 横長 8:5 でトリミング表示 |
| 推奨サイズ | 1600 × 1000 px |
| 推奨形式 | PNG（画面のスクリーンショットのため） |

**お願いしたいこと**
NajoshiteAI の**画面キャプチャ**を1枚ください。
スマホ画面なら、余白のある背景の上にスマホのモックを置いた画像だと、横長の枠にきれいに収まります。
新しく作るプロダクトが増えたら、`work-<プロダクト名>.png` の形で追加してください。

## アイコンについて

カード内のアイコン（円・矢印など）は、外部のアイコン素材サイトにこの作業環境からアクセスできなかったため、**すべて自前で描いた SVG** を `index.html` に直接埋め込んでいます。絵文字は使っていません。ライセンスの制約はありません。

Material Symbols（Apache-2.0）などの既成アイコンに差し替えたい場合は、`index.html` 内の `<svg class="card__icon">` および `.icon` の中身を置き換えてください。線の太さは `1.4`〜`1.6`、色は `currentColor` で統一しています。
