# assets / 画像の差し替えガイド

このフォルダの画像は、すべて**仮のプレースホルダー**です。
本番の画像が用意できたら、**同じファイル名で上書き**すれば、HTML を編集しなくても差し替わります。
（ファイル名を変える場合は `index.html` 内のパスも一緒に変更してください）

---

## 1. `logo-placeholder.svg` — ロゴ

| 項目 | 内容 |
|---|---|
| 用途 | ナビゲーション左上のシンボルマーク |
| 表示サイズ | 22 × 22 px（正方形） |
| 推奨形式 | SVG（推奨） / PNG なら 200 × 200 px 以上、背景透過 |
| 現在の中身 | 「常」の一文字を角丸の枠で囲んだ仮マーク |

**お願いしたいこと**
既存のロゴをいただければ、そのまま差し替えます。
ナビゲーションは常に**黒の半透明**なので、**白一色（単色）のロゴ**がいちばん Apple 的に収まります。
カラーのロゴしかない場合でも、いただければこちらで白の単色版を用意できるか確認します。

## 2. `favicon.svg` — ファビコン

| 項目 | 内容 |
|---|---|
| 用途 | ブラウザのタブ、ブックマークのアイコン |
| 表示サイズ | 16 × 16 px 相当まで縮小される |
| 推奨形式 | SVG |

**お願いしたいこと**
ロゴをそのまま縮小すると潰れることが多いので、**マークだけを切り出した、線の太い簡略版**があると理想的です。
なければ、いただいたロゴからこちらで簡略版を作ります。

## 3. `placeholder-member.svg` — メンバーの顔写真（4枚）

| 項目 | 内容 |
|---|---|
| 用途 | Team セクション |
| 表示サイズ | **円形**に切り抜いて表示（元画像は正方形） |
| 推奨サイズ | 800 × 800 px 以上 |
| 推奨形式 | JPG または WebP |

**用意していただきたいファイル**

```
assets/member-uehara.jpg    上原 貫太 さん
assets/member-anzai.jpg     安齋 隼 さん
assets/member-kobayashi.jpg 小林 壮志 さん
assets/member-yuki.jpg      結城 敬蔵 さん
```

**撮り方の希望**
- 4人とも**同じ場所・同じ明るさ**で撮ると、並べたときに揃って見えます
- 円形に切り抜くので、**顔が中央**、肩から上くらいの構図
- 背景は無地の壁、または作業場所など。ごちゃごちゃしていなければOK
- 顔写真を出したくない場合は、**後ろ姿・手元・アイコンイラスト**でも成立するデザインです

※ 写真をいただいた時点で、`index.html` の `src` をこちらで4つ書き換えます。

## 4. `placeholder-work.svg` — NajoshiteAI のサムネイル

| 項目 | 内容 |
|---|---|
| 用途 | Works セクション。黒背景の上に大きく表示し、スクロールで拡大する |
| 表示サイズ | 最大 1080 px 幅、横長 16:10 |
| 推奨サイズ | 1600 × 1000 px 以上（2倍の 3200 × 2000 px だとさらに鮮明） |
| 推奨形式 | PNG（画面のスクリーンショットのため） |

**お願いしたいこと**
NajoshiteAI の**画面キャプチャ**を1枚ください。
背景が黒なので、**ダークモードの画面**だと境目が溶けて Apple の製品ページのように見えます。
画像の下端はセクションの下端に接して表示されるので、**下側が途切れても不自然でない構図**（画面の上半分を大きく見せる等）がおすすめです。

## 5. 追加で用意すると良いもの（任意）

### OGP画像 `assets/ogp.png`
SNSでURLが共有されたときに表示される画像です。

- サイズ：1200 × 630 px
- 内容：ロゴ ＋ 「常陸・陸奥から笑顔を届ける。」のキャッチコピー
- 用意でき次第、`index.html` の `<meta property="og:image">` を追加します

### Hero（トップ）の背景
現在は**黒一色と、下からの青い光のにじみ**だけです。引き算の方針上、写真は入れない前提にしていますが、入れる場合は以下が合います。

- 横長 2000 × 1200 px 以上、**全体が暗いトーン**（白い文字を重ねるため）
- 例：暗い部屋で光るディスプレイ、夜の名取や仙台の風景

## アイコンについて

引き算の方針で、アイコンは**「サイトを見る ›」の矢印1つだけ**にしました。自前で描いた SVG を `index.html` に直接埋め込んでいます。絵文字は使っていません。
