# assets / 画像の差し替えガイド

このフォルダの画像は、すべて**仮のプレースホルダー**です。
本番の画像ができたら、**同じファイル名で上書き**すれば、HTML を触らずに差し替わります。
（形式を変える場合、例えば `.svg` → `.png` は、`index.html` のパスも変更してください）

---

## 1. `logo-placeholder.svg` — ロゴ

| 項目 | 内容 |
|---|---|
| 使う場所 | 画面上部の、生成り色のナビ（左端） |
| 表示サイズ | 36 × 36 px |
| 形式 | SVG 推奨／PNG なら 200 × 200 px 以上・背景透過 |
| 今の仮画像 | 黄色い丸に藍色の「常」 |

背景は生成り色（`#fff7e8`）です。**カラーのロゴがそのまま使えます**。
横長のロゴ（マーク＋社名）の場合は、ナビの社名テキストと重複するので、その旨を教えてください。表示を調整します。

## 2. `favicon.svg` — ファビコン

ブラウザのタブに出る小さなアイコンです。今は「波から昇る太陽」を仮で置いています。
ロゴのマーク部分を**線を太く・単純にした版**があれば差し替えます。なければロゴから作ります。

## 3. `placeholder-member.svg` — メンバー（4人）

| 項目 | 内容 |
|---|---|
| 使う場所 | メンバーのセクション |
| 表示 | **円形に切り抜き**、1人ずつ違う色の丸の上に置く（黄・コーラル・橙・水色） |
| 推奨サイズ | 800 × 800 px 以上の正方形 |

### おすすめ：似顔絵イラスト（描いてほしいもの）

このデザインは写真よりも**イラストの方が世界観に合います**。

- 4人それぞれの**胸から上の似顔絵**
- 線は**太めの藍色**（`#1a2456`）、塗りはシンプルに
- **背景は透過**（後ろの色の丸がそのまま背景になります）
- 4人とも**同じ画風・同じ構図**（顔が中央、少し笑顔）
- 余裕があれば、それぞれの**役割がわかる小物**（CEO＝旗、CFO＝電卓、CDO＝ペン、CSO＝地図 など）

### 写真を使う場合

- **背景を切り抜いた（透過）PNG** にすると、色の丸と馴染みます
- 切り抜かない場合も使えます（そのまま円形に表示されます）

ファイル名は次の形でください。受け取ったら `index.html` の4か所をこちらで書き換えます。

```
assets/member-uehara.png     上原 貫太 さん（CEO）
assets/member-anzai.png      安齋 隼 さん（CFO）
assets/member-kobayashi.png  小林 壮志 さん（CDO）
assets/member-yuki.png       結城 敬蔵 さん（CSO）
```

## 4. `placeholder-work.svg` — NajoshiteAI の画面

| 項目 | 内容 |
|---|---|
| 使う場所 | 「つくるもの」のカード（PC では左半分、スマホでは上側） |
| 表示 | 横長 16:10 で、枠いっぱいに切り抜き |
| 推奨サイズ | 1600 × 1000 px 以上 |
| 形式 | PNG |

NajoshiteAI の**画面キャプチャ**を1枚ください。
スマホアプリの画面なら、**藍色（`#283077`）の背景の中央にスマホの画面を置いた画像**にすると、カードに綺麗に収まります。

## アイコンについて

使っているアイコンは、ボタンの「→」と、テロップの「✦」型の星の2つだけです。どちらも自前で描いた SVG を `index.html` に直接埋め込んでいます（絵文字は不使用、ライセンスの制約なし）。
