メンバー専用

ブログ・作品・お知らせを書く

GitHub のアクセストークンで接続すると、ブログ記事や作品展示会の作品、お知らせ・実績を、そのままサイトに公開できます。トークンを持っているメンバーだけが公開できます。

1. GitHub に接続

このリポジトリへの書き込み権限があるトークンだけが使えます。トークンは GitHub 以外には送られません。

トークンの作り方
  1. GitHub の Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access で ToWhats-Inc.-HP だけを選ぶ
  3. Permissions → Repository permissions → Contents を Read and write にする
  4. 作成したトークン（github_pat_ で始まる文字列）を上の欄に貼る

リポジトリの共同編集者（Collaborator）になっている人のトークンだけが使えます。
